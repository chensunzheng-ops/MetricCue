# MetricCue 项目介绍

## 一句话说明

MetricCue 是一个本地优先、证据优先的内容运营数据诊断工具。它把平台导出的 CSV 转换为可追溯的问题信号、数据质量提示和实验建议，帮助使用者从“指标变了”走到“下一步验证什么”。

## 为什么做这个项目

内容运营复盘经常从手工查看阅读量、互动和发布时间开始。当数据量增加后，异常数据、内容结构变化和生产流程问题容易混在一起，结论也可能停留在主观判断。MetricCue 将这套工作整理为可重复运行的流程，同时明确区分事实、信号、假设和实验，避免把观察性关联直接写成因果结论。

## 已实现能力

- 校验 CSV 中的必填字段、重复记录、异常值、累计计数器重置和疑似敏感信息。
- 计算阅读、互动、完读、关注和转化等指标，并比较当前窗口与历史基准。
- 分析趋势异常、内容生命周期、主题分群贡献和生产流程效率。
- 输出不可变的运行目录，其中包含输入哈希、结构化证据、Markdown 报告和 SVG 图表。
- 通过 Codex Skill 将 `finding_id` 关联到有边界的运营实验建议，不重新编造指标。

## 一分钟演示顺序

1. 展示一组完全合成的公众号内容表现、内容属性和生产流程 CSV。
2. 运行 `metriccue analyze` 并打开生成的 `report.md`。
3. 从总体互动率下降进入主题分群和审核等待信号。
4. 打开 `evidence.json`，用 `finding_id` 核验报告中的数字。
5. 说明这些信号只是关联，并展示一个控制变量明确的下周实验。

## 项目边界

MetricCue 不登录或抓取平台，不自动发布或投放内容，不预测爆款，也不声称观察性数据已经证明因果关系。仓库案例全部使用合成数据；在真实用户验证完成前，不宣称节省了确定比例的时间。
